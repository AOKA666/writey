# Self-hosted fonts

UI / display (production):
- Newsreader (SIL Open Font License 1.1) — headlines
- IBM Plex Sans (SIL Open Font License 1.1) — UI and body

Handwriting specimen fonts (preview and export only):
- Caveat (OFL) — “Oxford Cursive”
- Patrick Hand (OFL) — “Drafting Script”
- Kalam (OFL), including Devanagari — “Kavya Devanagari”
- Dancing Script (OFL) — “Studio Loop” (Pro specimen)

These handwriting faces are labeled **Pending commercial licence** in the product UI.
They are used only as specimens. Do not claim that Hindi first-class commercial
fonts have been delivered, and do not treat OFL redistribution here as a closed
commercial audit. Licence texts are in `licenses/`.

Sources: Fontsource packages (upstream Google Fonts / IBM Plex), vendored into
this repository so the site does not request Google Fonts or other font CDNs at
runtime.
